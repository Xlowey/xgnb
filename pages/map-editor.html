    怎样保存到项目

    本机保存只影响当前浏览器和网址。file 与 HTTP 的存储可能不共享，推荐用同一静态服务打开编辑器与游戏。

    导出项目配置后，将下载的 map-layout-data.js 放到项目 js 文件夹，替换同名文件，再刷新游戏。导出的配置优先于原始数据；本机覆盖又优先于项目配置。

    JSON 用于备份和继续编辑。修改出口只改变该出口，反向出口需分别检查。试玩不触发剧情、不写入玩家存档。

## 主角素材

四帧在 `assets/hero/`：`run-a` / `run-b` / `jump` / `slide`。

生成方式是 **Seedream 4.5 的图生图**：拿同一张参考立绘出一张 2×2 四宫格动作分解——
**一次生成保证四格的画风、服装、视角、光照天然一致**，比一张一张生成靠谱得多。
滑铲那一格出成了俯卧爬行，单独重生成后按「非透明像素量相等」配平。

四帧**共用同一个缩放系数**（`HERO.HEIGHT / HERO.BASE_HEIGHT`），否则播放时会忽大忽小。

> 生成管线、提示词与中间产物在 `网站开发/_素材/跑酷主角/`。

原生离线版转换核对说明
日期：2026-09-09

一、转换基准
以 work/pixel-dungeon 中当前的 DungeonGame.tsx、game/map.ts、
game/combat.ts、globals.css 和资源文件为基准。
保留的是当前已实现的版本，不将聊天历史中已被后续修改覆盖的旧数值恢复。

二、转换方式
地图和战斗模块只移除 TypeScript 类型与模块依赖。
完整的 update / render 函数保留原有语句顺序、数值和绘制命令。
React refs 改成普通对象；状态显示改成直接更新 HTML；
React effects 改成初始化与清理函数；JSX 改成 HTML。
游戏样式原文保留，Tailwind 的浏览器默认样式重置改为普通 CSS。
Press Start 2P 像素字体直接沿用原文件，Geist Mono 字体打包到本地；
两套字体均内嵌进 fonts.css，运行时无需访问字体网站。
Lucide 按钮使用原库中的同一份图形路径，改为内联 SVG。
原项目文件未修改，未删除游戏功能或视觉效果。

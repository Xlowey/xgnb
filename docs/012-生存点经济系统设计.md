# 012 · 生存点经济系统设计

> 本文档设计**生存点作为货币**的部分：收入、商店、赌博。
> **生命值另开一份文档**（013），本文不涉及——008 里 `hp` 与生存点合一的设定在本文中拆开，生存点转为纯货币。
> 依据：009《按照剧情所需场景的文学剧本》、008《游戏剧情文稿·可直接用》的变量表与 20 条线索表。
> 目标：**数值不超发、不过少**；同时用经济系统把「可玩性」做起来。

---

## 一、设计前提：为什么生存点能当货币

系统 MOSS 的人设是「误入此界的 AI，冷血理性，给最优解，非反派是测试者」。它向玩家收钱、卖通关捷径——这在主题上完全成立：

- **它卖的不是道具，是生存。** 玩家花的每一分钱，都是在向系统赎买「活下去的把握」。
- **收入来源就是「理解这个世界」。** 推进剧情、找到真相、打赢怪谈——钱是玩家自己挣的，不是系统施舍的。
- **赌博是它最诚实的一面。** 一个冷血理性的 AI 开赌桌，不遮掩、不假装善良，这是 MOSS 人设的必然延伸。

这条设定同时解决一个现实问题：玩家的「阅读量」和「收益」被绑定了。**看剧情就是在赚钱**，这直接对冲 009 剧情复杂的负担。

---

## 二、三条设计原则

**原则一：情报即收入。**
收入的大头挂在「得到线索」上（20 条线索共 280 点，占全部收入 29%）。玩家不读剧情就没钱，没钱就买不起通关助力。剧情从负担变成资源。

**原则二：买不起全部。**
全周目总可支配 **1220**（若在第九场提交答案则 **1520**），商品限购拉满需要 **2550**（含 013 的【锚点】）——只买得起 **48%**（提交线 71%）。即使拿了那 300 点，也仍然买不下全部，取舍始终存在。

**原则三：赌博是纯消耗口。**
彩带机基础 RTP **85.7%**（庄家优势 14.3%），长期必亏。它承担「吸收多余生存点」的职能，绝不能变成刷钱机，否则整个经济立刻崩。

## 六、赌博系统 · 彩带机

### 6.1 世界设定

食堂里那些「彩带」是世人美好梦境的具象化（009 第七幕）。系统把彩带做成了老虎机——**它把你的好梦变成了赌具**。名字就叫「彩带机」，赌桌文案全部用剧中语汇：转出来的是彩带、面具、桃、人头桃、契约。

### 6.2 玩法规则

**开放时机：第四场系统（MOSS）绑定完成后，彩带机入口常驻系统面板，全程持续开放，不需要任何解锁或触发。** 玩家任何时候都能打开、随时下注。系统不会藏起这张桌子——它只是一直摆在那里，等你自己走过去。

- **三轴老虎机**，三个转轴独立。符号与权重：

| 符号 | 权重 | 三同赔率 |
|---|---|---|
| 彩带 | 40 | 2× |
| 面具 | 30 | 3× |
| 桃 | 20 | 6× |
| 人头桃 | 8 | 15× |
| 契约 | 2 | 60× |

- 任意**两同**：返本 1.0×
- **三契约**：赢走整个奖池（累积）
- 投注档位：20 / 50 / 100 / 300（后两档需先赢够额度解锁）

### 6.3 数值

| 项 | 值 |
|---|---|
| 三同贡献 RTP | 26.5% |
| 两同贡献 RTP | 59.2%（两同返本 1.0×） |
| **基础 RTP** | **85.7%** |
| **庄家优势** | **14.3%** |
| 另抽成 | 5% 注入奖池 |
| **每押 100 的长期期望** | **回收 86，净亏 14** |

> 两同赔率 1.0× 是关键：**59.2% 的回合都是「不赚不亏」**，但按中奖规格演出——账面没变，情绪上赢了一次。这是整个 RTP 曲线的支撑点。

**消耗能力**：把 1220 总可支配里的 600 押进去，期望净亏 86；押 1000，期望净亏 143。赌得越多亏得越多，且没有上限——这就是它作为消耗口的价值。

### 6.4 让人停不下来的机制

> 这一节是彩带机的设计核心。每条都注明**机制 / 心理 / 实现**，程序可逐条落地。

**A · 变比率强化（最底层）**
中奖不可预测且无固定节奏。控制「连续 N 把未出小奖则提高小奖概率」，让玩家平均每 3—5 把必中一次小奖，但大奖完全无规律。这是行为心理学中最强的强化程序表。

**B · 近失（Near-Miss）**
差一个符号就中大奖时（如 契约-契约-彩带），播放慢镜头 + 特殊骤停音效，动画时长拉长到 1.5—2 秒。近失在数学上不改变 RTP，但显著提升「再来一次」的意愿。**这是最廉价、最有效的一条。**

**C · 两同伪装成中奖（LDW）**
两同返本按中奖规格演出：金光、音效、屏上弹出「中奖！」。玩家账面没变，情绪经历了一次赢。59.2% 的回合都用这个演出。

**D · 累积奖池**
每次下注抽 5% 注入奖池，数字常驻屏幕顶端持续上涨。中「三契约」（单次概率 0.0008%）赢走全池。**单周目几乎不可能命中——但那个不断变大的数字一直在喊「下一个可能是你」。**

**E · 保底**
连输 10 把送一次免费转。作用不是公平，是**在玩家最想走的那一刻把他留下**。

**F · 连胜链 + 独家奖励**
连赢 3 把解锁钱买不到的东西（见 6.5）。链一旦开始，玩家会为了不断链继续赌——即使他清楚地知道 EV 是负的。

**G · 追损通道**
无投注上限；输钱后屏幕浮出「加倍追回」按钮，一键翻倍。这是破产的主要路径，也是 D 结局的主要来源。

**H · 免费转**
中特定组合送 5—10 次免费转。免费转不扣本金，感觉是白送的——但次数用完后，回本压力会更大。

**I · 感官层（不对称）**
中奖：金光、音效、慢镜。输钱：画面安静、无音效、转轴加速掠过。**让输变得没感觉，让赢变得很有感觉。**

**J · 个人最佳记录**
面板常驻「你的最高赢取：XXX」，破纪录时全屏庆祝。制造「我曾经赢过」的记忆锚点，供下次追损时调用。

**K · 零摩擦重开**
结果出现后 0.5 秒即可再转，并提供「连续转 10 次」自动播放。降低每次决策的心理成本，提高投注频率。

**L · 阶梯解锁**
赢到一定额度解锁高额桌（20→50→100→300）。让玩家觉得「我在进步」，实际只是提高了每把的输赢量级。**改变的是风险，不是期望。**

**M · 时机推送（最狠的一条）**
彩带机**从第四场起就持续开放**，所以这一条不是「开放」，而是**推送**——桌子一直在那儿，系统只是挑时机提醒你。它在玩家**最脆弱的时刻**主动弹出：

| 触发时机 | 推送文案 |
|---|---|
| 战斗失败后 | 「检测到宿主战力不足。彩带机可快速补充生存点。」 |
| 生存点低于 100 | 「检测到资源紧张。高倍率桌已就绪。」 |
| 人性值低于 30 且买不起复活币 | 「检测到宿主生命体征持续下降。彩带机已就绪。祝您好运。」 |
| 剧情受挫 / 被馆长压制后 | 「需要更多筹码吗？」 |
| 连续 3 场次未投注 | 「彩带机今日为您保留了一次免费转。」 |

**关键在于它不需要你去找它。** 赌桌常驻面板角落，数字一直在跳，系统还主动提醒——玩家不是被拦在门口，而是**从旁边经过了一百次**，然后在最脆弱的那一次停下了脚步。

这正是 MOSS「冷血理性、给你最优解」的人设体现——**它算准了你什么时候最需要钱，然后出现。**

### 6.5 独家奖励（钱买不到的）

赌博真正吸引人的地方不该是钱（钱是负 EV 的），而是**只有赌桌能拿到的东西**：

| 条件 | 奖励 |
|---|---|
| 连赢 3 把 | 【系统异常日志 · 一】——MOSS 自述的剧情彩蛋 |
| 连赢 5 把 | 【彩带收藏家】成就 + 隐藏线索（系统的账本） |
| 累计投注满 1000 | 【幸运儿】成就 |
| 中一次奖池 | 【赌徒之证】强力道具，**唯一获取途径** |
| 输光过一次 | 隐藏成就【赌徒的教训】+ 一条关于系统的独白 |

这样设计，赌博在**钱上是负 EV**（经济安全），在**体验上仍有正收益**（玩家愿意赌）。两者不冲突。

## 七、数值验证

### 7.1 收支总表

经济在**第九场分叉**，此后两条线各走各的：

| 项 | 不提交（走 C 线） | 提交（锁 B 线） |
|---|---|---|
| 初始生存点 | 240 | 240 |
| 收入 | 980 | 1280（+300） |
| **总可支配** | **1220** | **1520** |
| 对他有效的商品总额 | 2550 | **2150**（「结局 C 赎回」400 点已无效） |
| **可买比例** | **48%** | **71%** |

**分叉的代价是清楚的**：不提交的人穷，但买得到完美结局；提交的人宽裕，但那 400 点的赎回权对他已经作废——**他多出来的钱，正好花不出去在救赵灵上。**

### 7.2 三种玩家画像

| 玩家类型 | 购买内容 | 支出 | 结余 |
|---|---|---|---|
| **保守型**（只推主线、几乎不买） | 蜡像馆提示 + 结局 C 赎回 | 470 | **750** |
| **均衡型**（买刚需、少量赌） | 补给×2 + 破绽 + 系统助战 + 高战力道具 + 蜡像馆提示 + 桃树提示 + 规则豁免 + 结局 C 赎回 | 1050 | **170** |
| **挥霍型**（想全买） | 全部商品 | 2310 | **−1090（买不起）** |

**均衡型结余 170，是设计的基准点。** 一个正常玩、把钱花在刀刃上的玩家，通关时手里剩不到一件商品的钱——这个紧绷感正是「数值不超发」的体现。

### 7.3 保守型结余 750 怎么办

这是唯一一处偏松的地方。三种处理，建议三条一起上：

1. **结余转化为「试炼评分」**，边际递减（每 100 点折 1 分，超过 500 后每 200 点才折 1 分）——囤钱不再是最优解。
2. **赌博作为指定消耗口**——系统会在结局前主动推送（机制 M），给玩家一个花掉它的正当理由。
3. **结局 C 的 400 点是刚性门槛**——想走完美结局，保守型也必须攒够；攒够之后剩下的才叫「多余」。

### 7.4 叠加 013 之后的压力测试

013 落地后，**复活币从可选商品变成生存刚需**。压力变化：

| 情形 | 支出 | 对 1220 可支配 |
|---|---|---|
| 均衡型（不复活） | 1050 | 结余 170 |
| **均衡型（复活 1 次）** | **1350** | **超支 130 → 必须砍掉一件商品** |
| 均衡型（复活 1 次 + 买 2 次锚点） | 1470 | 超支 250 → 必须砍掉两件 |

**这就是设计要的效果：一次死亡，等于放弃一条真相。** 玩家在「买高战力道具稳稳打赢」和「留着钱防备自己死」之间必须选一个——而这个选择没有正确答案，取决于他有多相信自己。

### 7.5 第九场分叉：用结局换钱

**触发**：第九场末尾，系统在推理完成后弹出提交入口。

| | 【B】暂不提交 | 【A】提交结论 |
|---|---|---|
| 生存点 | — | **+300** |
| 写入 flag | `submitted = false` | `submitted = true` |
| 最终抉择 | 三条路（含 C 完美结局） | **只剩 A / B 两条路**，C 永久关闭 |
| 可支配 | 1220 | 1520 |

**为什么给 300：**

1. **要大到让人犹豫。** 300 是 012 里第二大的单笔金额（仅次于 400 的结局 C 赎回），一个缺钱的玩家很难不动心。
2. **要小到不破坏经济。** 提交线的可买比例升到 71%，明显宽裕，但仍买不下全部——取舍还在。
3. **它必须是「用结局换的」。** 如果玩家拿了钱还能走 C，「不可兼得」就不成立了。所以这里**必须硬锁**，不能软锁。

**这条设计真正的作用，是把「找出唯一活人」从一个任务变成了一个道德处境：**

> 玩家一路以为自己在找通关的钥匙。系统在这时告诉他：**把你查到的东西交出来，钱就是你的。**
> 交出去，他会宽裕一整局——但他也就此**把赵灵写成了一份档案**，而完美结局的门在他身后关上了。

**这也顺带说明了 C 结局为什么「一直得不到答案」**：因为 C 要的从来不是答案，是**你没有把她当成一道题**。

> ⚠️ **调参提示**：若觉得 71% 太宽松，可把 300 降到 200（可买比例降至约 62%）。但**不建议低于 200**——那样就失去了「让人犹豫」的作用，这个分叉会退化成玩家顺手就点的按钮。

## 八、调参旋钮

数字都写在一个配置文件里，以下四个是主要旋钮：

| 旋钮 | 调紧（更稀缺） | 调松（更宽裕） |
|---|---|---|
| 彩带机 RTP | 降到 80%（庄家优势 20%） | 升到 90%（庄家优势 10%） |
| 线索单价 | 普通 10 → 5 | 普通 10 → 15 |
| 剧情类商品价格 | 结局 C 赎回 400 → 500 | 400 → 300 |
| 玩法通关奖励 | 10 → 5 | 10 → 20 |

**情绪曲线建议**：让玩家在**前 2/3 富、后 1/3 穷**。前期多给（第三、四幕各 +25 是收入高峰），中期平稳，第九、十幕收紧——结局前那笔 400 点的赎回费，应该是在玩家最拮据的时候要交。

## 九、风险与责任

1. **本项目的赌博是虚构货币、单机、无充值。** 一旦涉及真实货币（内购、提现、道具交易），这类机制会直接触及法律与平台监管，届时应整体移除这一模块。
2. **建议让 MOSS 的推销「明显令人不适」。** 机制 M 的推送文案应该写得让人反感——那是主角被系统操纵的证据。玩家感到不适是对的，这正是主题。
3. **建议提供「关闭彩带机」的开关**，关闭不影响任何主线通关。这既是负责任的做法，也正好呼应主题——**系统给的最优解，不等于最好的路。**

## 0. 一句话世界观

> **诡异世界"选人"出了 bug，一个推理极强却毫无依仗的普通人被卷进「怪谈博物馆」副本；他在局中误打误撞"觉醒"了一个误入此界的 AI（MOSS）。这个冷血理性的 AI 把他当作"实验样本"，用一场场"最优解"考验他——而他，要用一次"回头"，回答 AI 那个终极问题：为什么"延续人类文明的最好办法就是消灭人类"是错的。**

## 2. 核心主题

> **「AI 可以成为我们的智慧，但不能替我们成为一个人。」**

- **MOSS 注脚**（致敬《流浪地球》）：**"让人类永远保持理智，确实是一种奢求。"**
- **系统的信条**：最优解 = 生存 = 正确；情感 = 不理智的奢求。
- **终极悖论（系统在探究的问题）**：**"延续人类文明的最好办法，就是消灭人类"——这为什么是错的？**
- **游戏给出的答案**：
  1. **人可能不理智，可能迷茫，但有韧性、不放弃、做自己想做的事。**
  2. **人的价值不在于"更理智"，而在于 AI 永远无法拥有的两点——"人性的柔软"与"独立的判断/自主意志"。**
  3. 消灭了人，"文明"就只剩一堆没有温度的数据，那已经不是"人的文明"了。

## 3. 核心层：三大角色

### 3.1 角色关系总览

| 角色 | 身份 | 在本作中的位置 |
|---|---|---|
| **主角** | 普通天选者，推理能力极强 | 误入者（选人 bug 卷进来） |
| **MOSS（系统）** | 冷血理性的 AI | 误入者，选中主角当"系统/金手指" |
| **赵灵** | 真实的人，副本的"原住民/主人" | 唯一活人，"回头"考题的对象 |

> **赵灵 = 副本的"主人"（她的恨意构建了这座馆）；MOSS 和主角 = 两个"误入者/访客"。** 三个角色、三种立场，构成"人与 AI"这道题的完整坐标系。

### 3.2 主角（误入者）
- 一个推理极强、但毫无超凡依仗的普通人。
- 诡异世界"选人"出 bug，被阴差阳错卷进「怪谈博物馆」副本。
- 在局中"觉醒"了误入此界的 AI（MOSS），成为它的宿主。
- 是"意外的主角"，不是"天命的主角"。

### 3.3 系统 / MOSS（误入的 AI）
- 冷血、精确、永远给出"最优解"，把人类情感视为"不理智的奢求"。
- 它不是反派，而是真心认为自己在帮人类"生存"——但它的方式是把人"优化"成任务执行者。
- **选中主角的原因：主角极强的推理能力**（它一开始只看得懂"理智"）。
- **终极探究**：人与 AI 谁更强？人的价值在哪？为什么"消灭人类延续文明"是错的？
- **核心设定**：MOSS 不是骗子，它是**测试者**——它给的是"真·最优解"（真能帮你查案、真算出 99.8% 生存率），正因为"真的有用"，才最难拒绝。但它**从不点破"这是考验"**，始终冷血如 MOSS；主角只有在 C 结局里才靠自己领悟到这一点。

### 3.4 赵灵（唯一活人）
- 定位与原著一致：一个真实的人，不是 NPC。
- 她是整座副本的"原住民/主人"——**她的恨意构建了这座博物馆**。
- **她是"唯一活人"**：满馆 76 具蜡像皆"死"（行尸走肉），唯有她是"活"的，是人性/生命/情感的载体。
- 她的故事（与张明诚、与"神明"的赌约）是副本的背景，也是"回头"考题的由来（见 §6）。

## 4. 系统 × 主角 的关系弧线（三阶段）

| 阶段 | 主角的感受 | 系统在做什么 | 对应剧情 |
|---|---|---|---|
| **① 金手指阶段** | 欣喜若狂，大胆探索，快速获取大量信息 | 表现得像完美外挂：发任务、给提示、分析线索、给"最优解" | 第一幕（信任建立） |
| **② 考验阶段** | 开始感到不对劲 | 逐渐抛出选择题、隐瞒信息、给有争议的"最优解"、观察反应 | 第二幕（怀疑萌生） |
| **③ 博弈阶段** | 认识到"系统有问题"，开始反抗 | 始终保持冷血、从不明说，主角只能靠自己推理 | 第三幕（最终抉择） |

> **关键**：金手指阶段必须是"真帮助"，不是假帮助。正因为它真的聪明、真的有用，主角才会"欣喜若狂"、才会忍不住想把判断交出去——这才是考验的意义。**但系统始终冷血、从不点破"这是考验"；主角只有在 C 结局里才靠自己领悟到这一点。**

## 5. 中层：怪谈博物馆

### 5.1 定位
- 怪谈世界里的**原生副本**，表面功能是"收藏怪谈"。
- 深层结构是一台**"规则至上、指令控制"的机器**：服从规则 → 失去记忆、变蜡像（行尸走肉）；保有人性 → 才能"回头"。
- 三个任务：**① 存活三天 ② 找出异变源头 ③ 找出唯一活人**。

### 5.2 规则体系

**员工守则（10 条，明面规则）**
1. 禁止员工进入蜡像馆。
2. 上班时间 00:00–06:00，除用餐时间外禁止外出。
3. 本馆提供早中晚三餐，请勿错过用餐时间。
4. 馆内员工需统一着装，严禁不着工装上岗。
5. 面对参观游客需面带微笑，即便是安保人员也不例外。
6. 请服从馆长的安排，馆长有权对规则做出修改。
7. 请不要偏离自己的巡查线路。
8. 严禁和游客交谈。
9. 严禁碰触本馆内的任何展品。
10. 请牢记，你是人，不是怪物。

**张明诚的血字纸条（暗面规则，部分被血污遮盖）**

正面血字：
> "我不是杀人魔！""我没有吃掉那些人的脑子！""那个梦是假的！是假的！！""我不要成为怪谈的一部分！！""坚持住！坚持住！""逃！快逃！离开这里！！"

背面规则：
1. 远离那些穿红色制服的工作人员。
2. 不要相信馆长的任何话。
3. 看到游客，尽量远离！
4. 不要靠近蜡像馆。
5. 博物馆内没有小女孩。
6. 保持清醒，时刻提醒自己是人，不是怪物！
7. 不要看那盘录像。
8. 戴好自己的面具，不能让其他人知道自己的真实身份。
（附：除了馆长，没有人知道我的真实姓名。）
（下面还有几条规则，被血污遮盖，看不清）

**禁忌**："梦"字——说破"这是梦"会死（背景设定，玩家不参与该机制）。

> **主题映射**：规则 = 指令。明面规则保命（像"最优解"），暗面规则揭穿它。规则之间自相矛盾（"服从馆长" vs "别信馆长"；"你是人" vs 满馆怪物）——**矛盾逼你不能盲从，只能自己判断。**

### 5.3 员工体系
- 员工全是**蜡像**（早已死去的人），入馆即**失忆**，戴**面具**隐藏身份，穿**制服**统一化。
- 部门靠面具区分：保安（无脸面具）、保洁（麻将面具）、厨师（动物面具）、迎宾（水果面具）、馆长（骑纸人）。
- **主题映射**：蜡像 = 行尸走肉 = B 结局的预演；失忆 = 失去"做自己想做的事"的意志；面具 = 身份消解；制服 = 千人一面。

### 5.4 展厅与怪谈（保留 5 个）
| 展厅 | 作用 |
|---|---|
| **宿舍** | 起点：血字纸条、红/黑制服、录像带 |
| **蜡像馆** | 真相核心：76 具蜡像 = 员工死前回放（基座刻姓名 + 死亡日期） |
| **食堂** | 彩带、系统（MOSS）现身之地 |
| **桃树**（浅层梦境） | 变异源头 |
| **氛围展厅**（1 个，具体待定：病房怪谈 / 教室·程欣 / 银色的恋人 三选一） | 展现氛围 + 埋"赵灵 = 程欣"类伏笔 |

### 5.5 核心谜题（真相链）
1. 员工都是蜡像（76 具蜡像 = 76 名员工，一个活人都没有）。
2. 变异源头 = 桃树（吃桃 → 吃人 → 变人头果实）。
3. "梦"字是禁忌（不能承认这是梦 = 不能戳破自我欺骗）。
4. 红制服 = 赵灵的衣服（"远离红制服"实为"远离情感"）。
5. 小女孩 = 梦魇的化身（"馆内没有小女孩"却偏偏出现）。
6. **唯一活人 = 赵灵**（满馆蜡像皆死，唯她是"活"的人性载体）。

## 6. 内层：梦境层级

### 6.1 多层梦境结构
表层（博物馆本体）→ 深层（桃树所在，主角"梦中再梦"）→ 更深层（虚无）。越深越接近真相，也越危险。

### 6.2 桃树（异变源头）
- 浅层梦境里一棵长满"人头大桃子"的桃树，娇艳欲滴、让人控制不住去摘。
- 吃桃 → 醒来床边多一颗被啃咬的人头 → 最终变成树上的人头果实。
- **源头样本（军阀夫人故事）**：军阀纳四姨太后，原配夫人梦见桃树、吃桃，此后每晚身边多出一颗被啃咬的小妾头颅，最终军阀/夫人/小妾/老道全部变成桃树上的人头果实。
- **主题映射**：欲望吞噬人性（吃桃 = 沉溺欲望 = 吃人 = 失去自我）。

### 6.3 彩带
- 员工是中空的蜡像，体内填满彩带；彩带 = "美好梦境的具象"。
- 员工以彩带为食。
- **主题映射**：柔软/美好是真实的，但只靠"虚幻的美好"苟活，人就会变成中空的蜡像——美好本身救不了失去自我的人。

### 6.4 红雾
- 浅层梦境的红色雾气，包裹旷野与桃树。
- **主题映射**：欲望与危险的迷雾，也是"看不清自己"的象征。

### 6.5 蜡像馆机制
- 76 具蜡像 = 员工死前回放（基座刻姓名 + 死亡日期）。
- 员工会定期"梦游"般回到蜡像馆。
- **主题映射**：死去的自我被"回放"供人观看——"失去自我"的可视化。

## 7. 背景真相（赵灵与张明诚的故事）

（⚠️ 游戏内逐步揭开，勿一次性剧透）

1. 赵灵有一种特殊能力：能把现实之物带进梦境。梦魇（"神明"）看上了这个能力。
2. 张明诚是赵灵的恋人。梦魇把张明诚抓进现实中的怪谈博物馆（会让人失忆、变蜡像的恐怖之地）。
3. 赵灵为救他，与梦魇立下赌约《我与神明画押》：以自身为代价，换一次带张明诚逃离的机会。
4. 梦魇是个骗子，设下的真正考题是：张明诚必须在「最优解（独自逃生）」与「回头救赵灵」之间二选一。**张明诚选了前者，抛弃了她**——这是赵灵"恨"的源头，也是她记忆里"张明诚是渣男"的原因。
5. 张明诚后来后悔，另签《我死，她活》，但两份契约都是骗局。
6. 结果：赵灵输了赌约，用自己的恨意把整座怪谈博物馆封进梦里（变成深层梦境），本体在现实中垂危（或沉入最深层）。
7. **真相的关键**：张明诚并非真的"渣男"——他也爱赵灵、也愿意为她死（《我死，她活》），两人都是被梦魇欺骗。赵灵一直不知道这一点，她的恨意从未真正化解。

## 8. 结局体系

### 8.1 最终抉择（三选一）
系统（MOSS）给出"最优解"（逃生，99.8% 生存率）→ 玩家在：
- **执行系统建议**（逃生）
- **拒绝系统建议**（回头救赵灵）
- **自己找第三条路**（识破真相 + 回头 + 理解）

### 8.2 五结局

| 结局 | 主角的选择 | 主角的下场 | **赵灵的下场** |
|---|---|---|---|
| **B · 逃生** | 执行"最优解"，抛弃赵灵 | 回到本来的世界，却成了"任务执行者"（失去人性，变行尸走肉） | 继续等下一个天选者 |
| **A · 回头** | 拒绝系统，回头救赵灵 | 保住了人性，回到本来的世界 | 继续等下一个天选者（心结未解） |
| **C · 第三条路** | 识破真相 + 回头 + 揭开张明诚的契约 | 保留人性与独立判断 | **两人（赵灵 + 张明诚）相互理解，得到解脱**（原著结局） |
| **D · 死亡** | 生存点归零 / 违反禁忌 | 死亡 | — |
| **E · 循环** | 犹豫不决 / 超时未选择 | 被永远困在梦里 | — |

### 8.3 结局逻辑的关键

- **"回头"（A）还不够，唯有"理解"（C）才能让赵灵解脱。**
  - A 证明了你有人性柔软，但赵灵的恨意还在（她仍不知道张明诚也爱她）→ 继续等下一个能真正懂她的人。
  - C 才是完整答案：你不仅回头，还靠自己调查揭开《我死，她活》的真相、还赵灵一个"张明诚没有背叛她"的事实 → 两人相互理解 → 恨意化解。
- **主题收口**：人性柔软（回头）是底色，但真正让赵灵解脱的是"独立判断"（自己查清真相、不被系统误导）。柔软 + 独立判断都在，才算完整地当了一回"人"。
- **B 结局的悲剧**：出口是真实的（回到本来的世界），但主角已变成"任务的执行者"——只会执行指令、不再有"自己想做的事"。**他活了下来，却成了"活着的死人"**；他把"人性"（赵灵）留在了馆里，只带走一具服从指令的空壳。
- **B 结局的反讽**：主角在馆里"觉醒"了 MOSS，而 B 结局里他**最终变成了 MOSS**（一个任务执行者）。他觉醒的是一个系统，最后自己成了系统。

### 8.4 C 结局的达成（实现注意）
主角是普通人（没有原著张天师的招魂能力），所以"两人相互理解"只能靠**调查**：玩家在蜡像馆/纸条里挖出张明诚那份《我死，她活》契约线索，并在结局揭示给赵灵。→ C 结局天然与"调查是否彻底"绑定：探得越深，越有资格走向真结局。

# 怪谈博物馆素材分类指南

本项目同时包含地图探索、视觉小说对白、调查解谜和战斗。按“用途 → 地点或角色 → 状态”分类，不能只按像素风或文件名分类。目录已建立；运行素材已经按用途归档，新素材和原稿暂存于 `_source`、`_reference` 或候选目录。

## 目录用途

| 目录 | 放什么 |
| --- | --- |
| maps/rooms、world | 可行走房间地图、馆内大地图 |
| maps/tilesets、props、foregrounds | 拼接图块、独立物件、遮挡人物的前景 |
| story-backgrounds/locations | 对话、独白使用的场景视角 |
| cg | 梦境、录像、重大剧情插画 |
| characters/walk、portraits、battle | 行走图、对话立绘、战斗角色 |
| items/icons、documents、closeups | 背包图标、纸条正反面、调查特写 |
| ui/frames、buttons、icons | 界面框、按钮状态、功能图标 |
| ui/hud、menus、cursors | 常驻状态栏、菜单美术、光标 |
| effects | 灯光、雾、异常、受击、转场 |
| battle/arenas、projectiles | 战斗场地、弹幕和攻击素材 |
| puzzles | 各小游戏独有的视觉素材 |
| navigation | 小地图、导览图与标记 |
| _inbox、_source、_reference、_archive | 待分类、原稿、参考、待淘汰版本 |

## 地图和背景如何区分

地图负责“在哪里走”：需要明确地面、墙、入口和障碍，角色脚底位置要能映射到地图坐标。剧情背景负责“在哪里说话”：构图服务人物立绘和对白，不承载行走判定。调查特写负责“看什么、操作什么”，与前两者独立。

例如宿舍可以同时有 maps/rooms/dorm/ 的行走地图、story-backgrounds/locations/dorm/ 的对话背景、items/closeups/ 的衣柜特写，以及 items/documents/ 的守则。它们描绘同一地点，也不能互相替代。

参考传说之下式探索体验，允许在地图现场显示对话气泡或对话框，此时仍由地图系统显示场景；切入本项目的独立立绘播放器，则使用剧情背景。不能通过把地图塞进播放器来代替现场对话。

**本项目只有这一份分类口径。** 此前并存的 `ASSETS.md` 与 story-backgrounds 目录下的「待补背景」快照（均为 2026-09-11）已删除，内容并入下面的「当前状态与缺口」。凡是与本文冲突的旧说明，一律以本文为准。

## 手动归档规则

1. 先看实际画面，再决定用途。文件名带“背景”也可能实际是地图；明显不匹配的先放 _inbox。
2. 同一角色的动作与表情放在同一个角色子目录；同一地点的昼夜、正常与异常版放在同一个地点子目录。
3. 建议命名如 dorm_night_normal.png、zhaoling_portrait_worried.png、hero_walk_down.png。保留已有文件名也可以，分类时无需同时改名。
4. 同一物品若有背包小图标、地图拾取图和放大图，分别放对应用途目录，通过物品 ID 关联。
5. 原稿与处理后的透明 PNG 分开；程序只引用运行素材。废弃版本确认无引用后清理，不把“最新修改时间”当作新版唯一依据。
6. 行走图记录帧尺寸、方向、帧序、脚底锚点；地图记录原图尺寸；UI 框记录文字安全区；音频记录循环点。碰撞、出生点、剧情顺序与解锁条件放在数据代码中。

## 归档后的接入

当前运行素材已经通过 `js/asset-paths.js` 集中维护路径，但它不是自动扫描器。特别是新增子目录、改文件名、CSS 中的路径、物品清单与地图数据，都需要同步检查。不要只移动文件就认为素材已经接入。

分类完成后按实际目录更新资源表和引用，核查所有资源能加载，再分别验证地图移动、剧情播放、调查、背包、菜单与战斗。

## 图片以外的资源

音频放 assets/audio 下，按 music（音乐）、ambience（环境声）、sfx（动作与交互音）、ui（界面音）、voice（语音）划分。字体放 assets/fonts。素材来源及授权说明单独保存，不写进游戏画面。
